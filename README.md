# Русификатор Sleeping With Sakuya Izayoi

![Прогресс](https://img.shields.io/badge/progress-95%25-orange)

---

## Дисклеймер: Данный контент является фанатским творчеством (производной работой), основанным на франшизе Touhou Project. Все права на оригинальных персонажей, мир и элементы вселенной принадлежат ZUN (Team Shanghai Alice). Этот проект не является официальным продуктом и не поддерживается автором оригинала.

## Автор визуальной новеллы: [SigyaadTeam](https://store.steampowered.com/developer/sigyaad)

*Проект выполнен в соло. Если вам понравился перевод, вы можете поддержать меня поставив звезду на репозиторий.*

## 🛠 Инструкция по установке

1. Скачайте архив с переводом (зелёная кнопка **Code** вверху страницы -> **Download ZIP**).
2. Распакуйте скачанный архив.
3. Перенесите файлы в корневую директорию игры в Steam с заменой файлов.
4. Русский язык включится автоматически при первом запуске игры.
